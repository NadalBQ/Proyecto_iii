# ROAD-SAFETY

- `main.py` es el sitio donde se escribe el flujo manual de la aplicación.
- `src/model.py` es un wrapper simple para entrenar, guardar, cargar, predecir y testear el modelo.
- `src/graph.py`, `src/routing.py`, `src/ui.py` y `src/weights.py` quedan reservados para integrar el resto del proyecto.
